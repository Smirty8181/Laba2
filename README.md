# Laba2

Учебное WPF-приложение на C# с формой регистрации пользователя.

## Форма включает

- Логин и пароль.
- Имя, фамилию и дату рождения.
- Переключатель наличия образования и поле для его указания.

Проект демонстрирует построение формы и обработку действия регистрации. Не используйте его для хранения настоящих паролей или персональных данных.

## Запуск

Откройте `WpfApp1.sln` в Visual Studio с поддержкой WPF. Требования к .NET Framework определяются настройками проекта.
